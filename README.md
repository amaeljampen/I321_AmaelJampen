## Installation

### Webstorm

Pour l'installation de l'IDE Webstorm, se rendre sur le site officiel [Jetbrains](https://www.jetbrains.com/webstorm/) (producteur de l'IDE), afin de télécharger l'installateur.

### Node.js

Pour l'installation de la plateforme de développement node.js, je me suis rendu sur le site oficiel de [Node.js](https://nodejs.org/fr/download), là ou j'ai pu choisir parmi les diffèrentes version de node.js, j'ai donc téléchargé la dernière version de l'installateur de node.js (qui était séléctionnée par défaut et étant indiquée comme LTS, pour latest).

### Git

Suite à une installation réalisée lors d'un autre cours, git était déja installé sur ma machine, pour vérifier qu'il s'agissait bien d'une des versions souhaitée, j'ai tapé la commande "git --version" permettant d'obtenir la version du logiciel, celle-ci étant 2.45.1 (donc 2.51.0 ou ultérieure).

<img width="209" height="35" alt="image" src="https://github.com/user-attachments/assets/90c69d6c-5f0d-41ca-a1e2-3277a2360c81" />

Si le logiciel n'est pas encore installé, il suffit de se rendre sur le site officiel de [Git-SCM](https://git-scm.com/) et de télécharger la dernière version de l'installateur git (la version LTS directement affichée sur la page d'acceuil)
